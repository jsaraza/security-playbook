Methodology
Collection, Examination, Analysis, Report

Collection: identify all devices data can be collected from
Examination: Filter data
Analysis: analyze data by correlating it with multiple pieces of evidence to draw conclusions
Reporting: report includes methodology and detailed findings from the collected evidence


write blockers: keep data original and unchanged

Disk image vs memory image: 
    - disk images are non volatile and durable
    - memory images are data inside ram and are volatile
